# أبحر بأمان | إطار BHDSF للسلامة الرقمية
لعبة عائلية لتعلّم السلامة الرقمية عبر ٤٠ محطة، مع حفظ التقدم والنقاط محلياً في المتصفح.

تصميم: فرج الهدار — مبادرة السلامة الرقمية، إطار BHDSF
Designed by Faraj Al-Haddar — Digital Safety Initiative, BHDSF Framework

## التشغيل

افتح `index.html` مباشرة، أو فعّل GitHub Pages للمستودع. سير العمل في `.github/workflows/pages.yml` ينشر ملفات الموقع بعد تحديث فرع `main`.

## التحديات المتكيفة

بعد ثلاث إجابات صحيحة متتالية للاعب، يعرض المحرك تحدياً أعمق من المجال نفسه. هذا تكيّف محلي قائم على قواعد، وليس خدمة ذكاء اصطناعي خارجية.

## الخصوصية

أسماء اللاعبين والنقاط والتقدم تحفظ في `localStorage` على الجهاز ولا تُرسل إلى خادم اللعبة. التخزين المحلي غير مشفّر؛ لا تدخلوا معلومات شخصية حساسة. HTTPS يحمي الاتصال بالموقع عند النشر عبر GitHub Pages، لكنه لا يشفر بيانات المتصفح.
